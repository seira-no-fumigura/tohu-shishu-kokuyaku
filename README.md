## 作品について

杜甫の詩集の国訳。国民文庫刊行会の『続国訳漢文大成 文学部』（上・中・下巻の上・下巻の下、昭和 3〜6 年）で、鈴木虎雄（1878–1963）の訳解。原詩に訓読・語釈・通釈が付く。国立国会図書館デジタルコレクションの全文テキスト（OCR）をそのまま収めた未校正の本文。

## 本文の作り方

国立国会図書館デジタルコレクション（インターネット公開）の全文テキスト（OCR）をそのまま収めた。1 段落が底本の 1 コマ（見開き）。校正はしていないので、振り仮名や柱の混じり、読み違いが残る。

## ファイル

| パス | 中身 |
|---|---|
| `honbun/` | 本文。1 行が 1 段落で、`段落ID<TAB>本文` の形です。原本の行の切れ目は ⏎ で示しています（⏎ は改行の印で、本文の字ではありません）。50段落ごとにファイルを分けています（31ファイル）。 |
| `tohu-shishu-kokuyaku.json` | 本文・底本・作品の説明をまとめた JSON（訳は入れず、`yaku/` だけに置いています）。段落ごとに原本のコマ番号があります。 |

段落ID（例: `tohu-shishu-kokuyaku-0001`）は、本文を直しても変わりません。データの形は雲居の文庫の作品リポジトリと同じです。

## 誤りを見つけたら


- **Issue で知らせる**：[「本文の誤り」の Issue を作る](https://github.com/seira-no-fumigura/tohu-shishu-kokuyaku/issues/new?template=teisei.yml)。段落ID・いまの本文・直した本文・根拠を書いてください。
- **直接直す**：`honbun/` の該当行を直して Pull Request を送ってください。段落IDと行の順番は変えないでください。

受け取った修正は、原本の画像と照らして確かめてから取り込みます。
